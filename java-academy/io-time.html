Lesson 14 · Core APIs & Functional Java

Files, I/O & Date-Time

Real programs save data and deal with dates. Learn the modern java.nio.file API, readers and writers, character encodings, a robust CSV parser — and the java.time API that finally makes dates pleasant.

⏱ 45 min🎯 Intermediate🧩 Prerequisite: lessons 10, 13

You will be able to

  • Read and write files with Files and Path
  • Always specify a character encoding
  • Process large files line by line
  • Parse CSV into records, tolerating bad lines
  • Use LocalDate, Instant, Duration and Period
  • Format and parse dates, and know the Android specifics

14.1Path and Files

Path represents a location; the static methods of Files do the work. For small files, read and write everything in one call. (This example uses a temporary directory so it runs anywhere.)

🔤

14.3Parsing CSV into records

A typical import job: read lines, skip the header, turn each line into a record, and collect errors instead of crashing on the first bad line.

Real CSV can contain quoted fields with commas inside ("Smith, Ada"). For production imports use a library such as Apache Commons CSV or OpenCSV.

14.4The java.time API

java.time (Java 8) replaced the confusing Date and Calendar. All its types are immutable and thread-safe. Pick the type that matches what you mean:

TypeRepresentsExample
LocalDatea calendar date, no time or zonebirthday, expense date
LocalTimea wall-clock time“remind me at 20:00”
LocalDateTimedate + time, no zonea meeting in “local time”
Instanta point on the global timeline (UTC)timestamps, logs, server data
ZonedDateTimedate + time + zone rulesconverting between time zones, DST
YearMonth, DayOfWeek, Monthpartial valuesmonthly reports
Duration / Periodmachine time (seconds) / human time (days, months)timeouts / subscriptions
🧪
Make “now” testable

Calling LocalDate.now() deep inside your logic makes tests depend on the day they run. Pass a java.time.Clock (or the date itself) in, and use Clock.fixed(...) in tests. Spendly's summary code takes the month as a parameter for exactly this reason.

14.5Files and time on Android

  • No free file system: an app may write freely only to its private directories — context.getFilesDir() (persistent) and context.getCacheDir() (may be cleared). They're deleted when the app is uninstalled.
  • User documents (downloads, photos) go through the Storage Access Framework or MediaStore, not raw paths.
  • Never do I/O on the main thread — it freezes the UI and can trigger “Application Not Responding”. Lessons 15 and 19 show how to move work to a background thread.
  • Structured data belongs in a database (Room, lesson 20) or preferences, not hand-rolled files.
  • java.time is built in from API 26 (our minSdk). For older devices enable core library desugaring.

14.6Exercises

Exercise 1 — Word count Easy

Write a text to a temporary file, then report its number of lines, words and characters (like Unix wc).

Exercise 2 — Next birthday Medium

Given a birth date and a fixed “today” (2026-03-14), compute the date of the next birthday and how many days remain. Handle birthdays already passed this year — and 29 February.

Exercise 3 — Weekly spending Challenge

From CSV lines date,amount, print the total per ISO week (Monday-based), in order, formatted like Week of Mon 2 Mar: 12.30.
