Lesson 19 · Android with Java

Building UIs with Views

Android's View system is how Java apps draw their screens: XML layouts, Material components, View Binding to reach them safely from code, and RecyclerView for lists of any length. By the end you can build every screen of the final project.

⏱ 75 min🎯 Intermediate🧩 Prerequisite: lesson 18

You will be able to

  • Read and write XML layouts
  • Choose between Linear, Frame and ConstraintLayout
  • Access views with View Binding
  • Handle clicks, text input and validation errors
  • Build lists with RecyclerView, ListAdapter and DiffUtil
  • Use Material 3 components, themes, dark mode and insets

19.1Views, ViewGroups and the layout file

Everything on screen is a View (a button, a text, an image). A ViewGroup is a view that contains and positions other views. A screen is a tree of them, usually described in an XML file in res/layout/ and turned into objects (“inflated”) at runtime.

android:id="@+id/…"
Creates an ID so code can find the view (+ = create it).
layout_width/height
match_parent (fill the parent), wrap_content (as big as the content), or a size in dp. 0dp means “let constraints/weights decide”.
padding vs layout_margin
Space inside the view's border vs outside it.
?attr/…
A value from the current theme — it adapts to light/dark mode and Material You colours.

Open a layout and switch between Code, Split and Design (top right). The Design view lets you drag widgets, the Attributes panel edits properties, and tools:text="…" shows sample data in the preview only.

Every view in a ConstraintLayout needs at least one horizontal and one vertical constraint. 0dp (“match constraints”) makes title stretch between the avatar and the amount.

19.3View Binding: type-safe access to views

With buildFeatures { viewBinding = true }, Gradle generates a class per layout — activity_profile.xml → ActivityProfileBinding — with a typed field for every view that has an ID (name_label → nameLabel). No casts, no nulls, no “wrong layout” crashes.

DiffUtil compares the old list object with the new one. If you mutate the same ArrayList and submit it again, nothing updates. Always submit a fresh (preferably immutable) list — which is what immutable state from a ViewModel gives you for free (lesson 20).

19.6Material 3 components

The com.google.android.material:material library provides Google's Material Design 3 widgets. With a Theme.Material3.* app theme they adapt to light/dark mode and, on Android 12+, to the user's wallpaper colours (DynamicColors).

Buttons

MaterialButton (filled, tonal, outlined, text, icon), FloatingActionButton for the main action.

Containers

MaterialCardView, MaterialToolbar in an AppBarLayout, bottom sheets.

Selection

Chip/ChipGroup, MaterialSwitch, MaterialRadioButton, Slider.

19.7Themes, dark mode and edge-to-edge

  • DayNight themes switch automatically; put dark overrides in values-night/themes.xml. Force a mode in code with AppCompatDelegate.setDefaultNightMode(MODE_NIGHT_YES) — Spendly's settings screen does.
  • Refer to theme colours (?attr/colorPrimary) instead of hard-coded hex values in layouts, so dark mode and dynamic colour just work.

19.8Accessibility basics

  • Every icon-only button and meaningful image has a contentDescription; decorative images use importantForAccessibility="no".
  • Touch targets are at least 48 × 48 dp.
  • Text uses sp and survives the largest font size without being cut off.
  • Colour is never the only signal (pair a red amount with a minus sign or icon) and contrast is sufficient.
  • Test with TalkBack on and with Android Studio's Accessibility Scanner/layout inspector warnings.

19.9Exercises

Exercise 1 — Tip calculator screen Easy

Build a screen with a bill-amount TextInputLayout, a ChipGroup for 10 / 15 / 20 %, and a TextView that shows the tip and total, updating as the user types or picks a chip. Use View Binding.

Exercise 2 — A contacts list Medium

Show a list of record Contact(long id, String name, String phone) in a RecyclerView with a ListAdapter. Tapping a row opens the dialler with an implicit intent (Intent.ACTION_DIAL, Uri.parse("tel:" + phone)). Add a search field that filters by name and submits a new list on every keystroke.

Exercise 3 — Landscape layout Challenge

Create res/layout-land/activity_main.xml for your tip calculator that places the input on the left and the result on the right using ConstraintLayout and a vertical Guideline at 50 %. Keep the same IDs — your Java code doesn't change at all. Why?

View Binding generates one class per layout name; both variants share the IDs, so the same fields exist. Android picks the right file at inflation time.
