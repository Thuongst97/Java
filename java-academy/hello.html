2.1Your first program

Every Java application starts at a method called main, which lives inside a class. Press ▶ Run to execute it right here — then change the text and run it again (Ctrl+Enter works inside the editor).

Five lines, and every word matters:

public class Hello
Declares a class named Hello. In Java all code lives inside classes. A public class must be saved in a file with the same name: Hello.java.
public static void main(String[] args)
The entry point the JVM looks for. public: callable from outside. static: belongs to the class, so no object is needed. void: returns nothing. String[] args: the command-line arguments.
{ … }
Curly braces delimit the class body and the method body.
System.out.println("…");
Prints text followed by a line break. System is a class from the standard library, out is its standard-output stream. Text in double quotes is a String. Every statement ends with a semicolon ;.

2.2Statements, printing & comments

A method body is a list of statements executed top to bottom. Each ends with ;. Whitespace and line breaks are ignored by the compiler — indentation is for humans.

⚠️
What if the user types “abc”?

nextInt() throws an InputMismatchException and the program crashes. Lesson 10 shows how to catch exceptions; lesson 06 shows Integer.parseInt. Another classic trap: after nextInt() the line break is still waiting, so a following nextLine() returns an empty string. Reading every line with nextLine() and converting it yourself avoids that.

2.5What happens when you press ▶

Java is compiled and statically typed: the compiler checks the whole program for type errors before it runs, then produces portable bytecode — “write once, run anywhere”.

  • javac reports every type error at compile time — an entire class of bugs never reaches your users.
  • The JVM starts by interpreting bytecode, measures which methods are “hot”, and compiles those to optimised machine code (the JIT, just-in-time compiler). That's why Java is fast.
  • On Android, the same Java source is compiled by javac, converted to DEX by D8, shrunk by R8 in release builds, and run by ART. Android implements most of the java.* standard library, so almost everything you learn in lessons 02–16 works on a phone.
🔍
See the bytecode yourself

After compiling, run javap -c Hello. You'll see instructions such as getstatic java/lang/System.out, ldc "Hello, Java!" and invokevirtual println — the JVM's “assembly language”. In Android Studio, View → Show Bytecode does the same for the open file.

2.7Reading compiler errors

Errors are the compiler helping you. Each one says where (file:line, plus a ^ under the exact spot) and what. This file has four mistakes:

Only one error? javac works in phases: it must first parse the file (syntax), and only if that succeeds does it check meaning (names and types). Add the semicolon and compile again:

  • cannot find symbol — a typo, a missing import, or a variable declared later / in another scope.
  • incompatible types — "2025" is a String; 2025 is an int.
  • ';' expected, reached end of file while parsing — punctuation: a missing semicolon or closing brace.
  • Fix errors from the top down: one mistake often causes follow-up errors.
💡
Let the IDE fix it

Android Studio underlines errors in red as you type. Put the caret on one and press Alt+Enter (⌥+↩): it offers to import a class, create a missing variable, or fix a type.

2.8Why Java?

Java was released by Sun Microsystems in 1995 and is now stewarded by Oracle and the open-source OpenJDK community, with a new release every six months and a long-term-support (LTS) release every two years (17, 21, 25…).

Everywhere

Android apps, banking and e-commerce back ends (Spring), big-data tools (Kafka, Spark, Elasticsearch), Minecraft, IDEs — billions of devices run Java bytecode.

Safe & readable

Static types, no manual memory management (the garbage collector frees memory for you), and explicit code that stays readable in huge teams.

A huge ecosystem

Maven Central hosts hundreds of thousands of libraries. Whatever you need — JSON, HTTP, databases, testing — it already exists.

The JVM foundation

Kotlin, Scala and Groovy all compile to the same bytecode. Knowing Java means understanding the platform under all of them — including Kotlin on Android.

🤖
Java and Kotlin on Android

Google calls Android “Kotlin-first”, but Java is fully supported: the framework itself is written in Java, the Android SDK and every AndroidX library work from Java, and Java and Kotlin can live in the same project and call each other freely. Many production apps are mostly Java. What you learn here transfers directly.
