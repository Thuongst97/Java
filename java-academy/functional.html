Lambdas, Method References & Streams

Since Java 8 you can pass behaviour around as values. Lambdas make click listeners and callbacks one-liners, and the Stream API turns loops full of bookkeeping into readable data pipelines.

You will be able to

  • Use and compose java.util.function types
  • Replace lambdas with method references
  • Build stream pipelines: filter, map, sort, reduce
  • Group and summarise data with collectors
  • Know when a plain loop is better

13.1Functional interfaces and lambdas

A functional interface has exactly one abstract method — Runnable, Comparator, View.OnClickListener. A lambda is a compact implementation of that one method: (parameters) -> body.

👆
On Android

Every listener becomes a one-liner: button.setOnClickListener(v -> viewModel.save()); instead of a six-line anonymous class. Lambdas don't capture the outer this unless they use it, which helps avoid the leaks from lesson 09.

13.3Method references

When a lambda only calls an existing method, a method reference Class::method says the same thing more clearly. There are four kinds:

KindMethod referenceEquivalent lambda
Static methodInteger::parseInts -> Integer.parseInt(s)
Instance method of a particular objectSystem.out::printlnx -> System.out.println(x)
Instance method of an arbitrary object of a typeString::toUpperCases -> s.toUpperCase()
ConstructorArrayList::new() -> new ArrayList<>()

Android Studio offers “Replace lambda with method reference” via Alt+Enter whenever it's possible.

13.4Streams: source → operations → result

A stream is a sequence of elements flowing through a pipeline. It has a source (a collection, array, range…), zero or more lazy intermediate operations (filter, map, sorted…) and one terminal operation (toList, count, forEach…) that triggers the work. Streams never modify their source.

Loop
Stream

Elements flow one at a time through the whole pipeline, and only as many as needed: “four” and “five” are never even filtered.

13.7Pitfalls and good style

  • No side effects in intermediate operations. Don't add to an outside list inside map or filter; collect instead.
  • A stream can be consumed only once. Reusing it throws IllegalStateException: stream has already been operated upon or closed. Keep the collection and call .stream() again.
  • Stream.toList() (Java 16) returns an unmodifiable list; use collect(Collectors.toCollection(ArrayList::new)) if you need to mutate the result.
  • Don't use parallel() by reflex. It helps only for large CPU-bound workloads; on a phone it mostly costs battery.
  • Loops are fine. If a pipeline needs peek, indexes, early return or checked exceptions, a for loop is often clearer.
🤖
Streams on Android

java.util.stream and java.util.function exist on Android 7.0 (API 24) and above; with minSdk 26 (this course) you can use them freely. For even older devices, Android Gradle Plugin's core library desugaring backports them.

13.8Exercises

Exercise 1 — Clean names Easy

From List.of(" ada ", "", "Linus", "ada", " grace") produce the sorted, distinct, capitalised names: [Ada, Grace, Linus].

Exercise 2 — Longest word per letter Medium

For a sentence, map each first letter to its longest word, sorted by letter. Hint: groupingBy with Collectors.maxBy, or toMap with a merge function.

Exercise 3 — Monthly report Challenge

Given expenses with a YearMonth, print for each month (in order) the total and the most expensive category. This is the core of Spendly's summary screen.
