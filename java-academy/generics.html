Generics

Generics let you write one class or method that works for many types while keeping full compile-time type safety. They're why List<String> can't accidentally hold an Integer — and understanding them makes the collections, streams and Android APIs ahead much easier.

11.2Generic classes and records

Declare type parameters in angle brackets after the class name. By convention they're single capital letters: T (type), E (element), K/V (key/value), R (result).

Type arguments must be reference types: Box<int> doesn't compile — use Box<Integer> and let autoboxing do the rest.

11.3Generic methods

A method can have its own type parameters, declared before the return type. The compiler infers them from the arguments.

11.4Bounded type parameters

Sometimes you need to call methods on T. A bound <T extends X> restricts T to X or its subtypes (for interfaces too — it's always extends), and in return lets you use X's methods.

Multiple bounds use &: <T extends Number & Comparable<T>> (a class bound must come first).

11.5Wildcards and PECS

Generics are invariant: even though Integer is a Number, a List<Integer> is not a List<Number> — otherwise you could add a Double to a list of integers. Wildcards restore flexibility:

Reading JDK signatures

Now you can decode Collections.sort(List<T> list) with <T extends Comparable<? super T>>: “T must be comparable to itself or to one of its supertypes”. Wildcards in your own APIs belong in parameters, rarely in return types.

11.6Type erasure

Generics exist only at compile time. The compiler checks types, inserts casts, then erases type arguments: at runtime a List<String> and a List<Integer> are both just List. This kept old bytecode compatible, but has consequences:

  • No new T(), new T[n] or T.class — pass a Class<T> (Room and Gson do exactly this).
  • No instanceof List<String>.
  • You can't overload f(List<String>) and f(List<Integer>) — after erasure they clash.
  • Static fields can't use the class's T — there is only one static field for all parameterisations.
