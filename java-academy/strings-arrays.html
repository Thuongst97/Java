Strings are immutable

No String method changes the string — toUpperCase(), replace() and friends all return a new String. Writing name.trim(); on its own line does nothing; you need name = name.trim();. Immutability makes strings safe to share between threads and to use as map keys.

6.3Building strings with StringBuilder

Because strings are immutable, result += piece inside a loop creates a brand-new string every iteration — O(n²) copying. StringBuilder is a mutable buffer designed for building text step by step.

A single expression like "a" + x + "b" is fine — the compiler optimises it. Use StringBuilder when you build text in a loop.

6.4Text blocks and formatting

A text block (Java 15+) starts with """ and a line break. Indentation shared by all lines is removed, so you can indent it with your code. Perfect for JSON, SQL and multi-line messages.

🌍
Locale matters on Android

String.format("%.2f", 3.5) prints 3,50 on a German phone. For user-visible text that's right; for machine formats (JSON, CSV, file names) pass Locale.ROOT: String.format(Locale.ROOT, "%.2f", x).

6.5Working with characters

A char is one UTF-16 unit; emoji and some scripts need two. Use code points when counting what users see as characters.

6.6Arrays

An array is a fixed-size, ordered block of elements of one type. Its length is set at creation and never changes. Elements get default values: 0, 0.0, false, '\u0000' or null.

6.7The java.util.Arrays toolbox

The first line differs on every run: arrays inherit Object.toString(), which prints the type ([I = int array) and a hash code.

6.8Two-dimensional arrays

Java has no true matrices: a 2-D array is an array of arrays. Rows can even have different lengths (“jagged” arrays).

📦
Arrays vs lists

Arrays are fixed-size and low-level. When you need to add and remove elements, use ArrayList (lesson 12). On Android you'll still meet arrays in APIs like String[] resources, byte[] for files and images, and int[] for permissions results.
