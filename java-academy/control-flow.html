Control Flow

Programs make decisions and repeat work. Master if, the modern switch expression, every kind of loop, and the keywords that steer them.

⏱ 45 min🎯 Beginner🧩 Prerequisite: lesson 03

You will be able to

  • Branch with if / else if / else
  • Use arrow-switch and switch expressions
  • Avoid the classic fall-through bug
  • Choose between while, do-while, for and for-each
  • Use break, continue and labels
  • Trace nested loops by hand

4.1if, else if, else

The condition in parentheses must be a boolean — Java will not treat 0 or null as false. The first branch whose condition is true runs; the rest are skipped.

⚠️
Always use braces

Without { } only the next statement belongs to the if. Adding a second indented line later silently runs it every time. Android Studio's formatter and every style guide insist on braces — so should you.

4.2The classic switch statement

switch compares one value against constant case labels. It works with int, char, String, enums (and, with patterns, any type — lesson 09). In the old colon form, execution falls through into the next case unless you break:

4.3Arrow switch and switch expressions

Since Java 14, case X -> labels never fall through, can list several values, and a switch can be an expression that produces a value. Prefer this form in new code.

💡
Exhaustiveness

A switch expression must cover every possible value, so you usually need default. With an enum or a sealed type (lesson 09), listing every constant is enough — and the compiler tells you when someone adds a new one.

4.4while and do-while

while checks the condition before each iteration (may run zero times). do-while checks after (always runs at least once) — handy for “ask until valid” input loops.

4.5for and the enhanced for-each loop

The classic for (init; condition; update) is ideal for counting. The for-each loop for (Type x : collection) visits every element of an array or collection without an index.

🔁
Which loop?

for-each when you need every element · for when you need the index or a custom step · while when you don't know in advance how many iterations · do-while when the body must run once. Lesson 13 adds streams, which often replace loops entirely.

4.6break, continue and labels

break leaves the innermost loop (or switch); continue skips to its next iteration. A label lets you target an outer loop.

Labels are rare in practice; extracting the nested loops into a method and using return (lesson 05) is usually clearer.

4.7Nested loops: tracing by hand

The inner loop runs completely for each iteration of the outer loop. Being able to predict output like this is a core skill — try before running.

4.8Exercises

Exercise 1 — FizzBuzz Easy

Print 1 to 15, but “Fizz” for multiples of 3, “Buzz” for multiples of 5 and “FizzBuzz” for both. Write it once with if and once with a switch expression.

Exercise 2 — Guess the number Medium

The secret is 42. Read guesses until the user finds it, answering “higher” or “lower”, then print the number of attempts.

Exercise 3 — Primes below 50 Challenge

Print every prime number below 50. A number is prime if no divisor from 2 up to its square root divides it. Use a labelled continue.
