A.7Android rules of thumb

  • Never block the main thread: database, network and file work go to a background executor or WorkManager.
  • Only the main thread touches views — deliver results with LiveData.postValue.
  • Keep screen state in a ViewModel; never keep Activities, Views or Contexts in ViewModels or static fields.
  • Java language features up to 17 work everywhere; Java library APIs depend on the device's API level (List.of 30, strip() 33, Stream.toList() 34) — run Lint.
  • Strings, colours and sizes live in res/; use dp for layout and sp for text.
  • Persist enums by name(), money as long cents, dates as epoch days or ISO strings.
  • Ask for runtime permissions (notifications, camera, location) when the user needs the feature.
  • Never commit keystores or passwords; keep mapping.txt for every release.

A.8The mastery checklist

Tick these honestly. When every box is ticked, you're no longer learning Java — you're using it.

Language

  • I can predict the output of expressions with casts, integer division and + on strings.
  • I explain primitives vs references, pass-by-value and the string pool.
  • I design immutable classes and records, and implement equals/hashCode correctly.
  • I choose between interface, abstract class, enum, record and sealed type deliberately.
  • I read generic signatures with wildcards (PECS) without fear.

Libraries

  • I pick the right collection for the job and know its complexity.
  • I write stream pipelines with grouping collectors — and know when a loop is clearer.
  • I handle errors with specific exceptions, causes and try-with-resources.
  • I use java.time correctly and inject a Clock.
  • I fix race conditions with synchronization, atomics or immutability.

Engineering

  • I set up and run unit tests in Android Studio and on the command line.
  • I write testable code with injected dependencies and fakes.
  • I debug with breakpoints instead of guessing.
  • I keep builds green with CI and Lint.

Android

  • I build screens with Views, View Binding and RecyclerView.
  • I structure apps in UI / ViewModel / domain / data layers.
  • I persist data with Room and schedule work with WorkManager.
  • I've built and shipped Spendly — or my own app.
